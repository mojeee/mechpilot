# Code of conduct

MechPilot is a place to build a good CAD tool together. Everyone taking part, in issues, pull
requests, discussions and reviews, agrees to this.

## Expected

- Be respectful and direct. Disagree about the work, not about the person.
- Assume good faith. Ask before judging.
- Keep feedback specific and actionable: what is wrong, where, and what would be better.
- Welcome newcomers; point them to the docs instead of dismissing a question.
- Credit other people's work.

## Not accepted

- Insults, personal attacks, harassment, discrimination of any kind.
- Publishing someone's private information.
- Sustained disruption of discussions or reviews.

## Enforcement

Report a problem by opening an issue marked "conduct" or, if it should stay private, by contacting
the maintainer through GitHub (profile `mojeee`). Reports are handled confidentially. The
maintainers may edit or remove contributions and comments, and may temporarily or permanently ban
anyone who breaks these rules.
