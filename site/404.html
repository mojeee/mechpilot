Production drawings to ISO standards, with 3D parts built in.

MechPilot is a desktop CAD app for mechanical design companies: draw, dimension and annotate to ISO 128, 129-1 and 7200, turn a sketch into a part, and keep the drawing linked to the model. Free and open source. Runs on your computer. Your files stay yours.

Build from source Downloads (coming with the first release)

In development, milestone by milestone, in the open. Version 0.3.0.

2D first

Lines, arcs, dimensions, tolerances and ISO 286 fits, surface texture, GD&T frames, sheets A4 to A0 with frame and title block. Vector PDF and DXF out.

3D where it helps

Extrude, revolve, holes, fillets, patterns on a parametric feature tree. Change a value and the part rebuilds; the drawing views follow. STEP in and out.

Checks on every change

Under-constrained sketches, missing dimensions, fits that do not exist, empty title-block fields: each finding on the drawing, with a one-click fix.

What you can count on

  • Local-first: no account, no cloud, no telemetry. The optional AI assistant uses your own API key.
  • An open, documented, versioned file format (plain JSON) that diffs well in Git. Autosave and crash recovery.
  • Millimetres in double precision; nothing is rounded on save, load or export.
  • Every drawing rule and table value cites its standard and clause. ISO by default, ASME as an option.
  • Apache-2.0. No GPL dependencies, checked in CI.

Files that open everywhere

DXF (R12 and 2000+ subset) for drawings, STEP for parts, vector PDF at true scale for the shop floor. DWG is not written (the only free library is GPL); DXF covers the exchange.
