ISO 21920-1 surface texture symbols and the Ra series

How surface texture is indicated on a drawing: the graphical symbol, the parameter and its limit value, such as Ra 1,6.

Graphical symbols

SymbolMeaningFigure
anyAny manufacturing process permittedFigure 4 a)
removal-requiredMaterial shall be removedFigure 4 b)
removal-not-permittedMaterial removal is not permittedFigure 4 c)

ISO 21920-1:2021, 6.2 and Figure 4. ISO 21920-1 symbols carry a short horizontal bar above the short leg, which distinguishes them from the ISO 1302 symbols and from areal surface texture symbols (ISO 21920-1:2021, 6.2, NOTE 2).

Minimal indication

Graphical symbol, then the parameter symbol and its tolerance limit value, separated by a single blank, e.g. Ra 1,6 written under the horizontal line of the long leg (ISO 21920-1:2021, 6.1, 6.3.2 and Figure 5).

Parameters with default values: Rz Ra Rp Rv Rq Rmax Rt Pt (ISO 21920-1:2021, 6.3.2, NOTE 1 (defaults in ISO 21920-3:2021, Tables 3 to 6))

Symbol proportions

Notes from the data file

  • Ra values are micrometres by convention of the standard; raSeriesUnit says so explicitly. Every length on the symbol is in mm.
  • Whether the N grade numbers survive in ISO 1302:2002 or ISO 21920 was not checked; MechPilot does not write N numbers on drawings.
  • Complete indications (tolerance type, acceptance rule 16 % / max, filter types and nesting indices, evaluation length, manufacturing process, lay) follow ISO 21920-1:2021, 6.4 and Figures 7 to 9; MechPilot's first version writes only the minimal indication plus an optional process text.
