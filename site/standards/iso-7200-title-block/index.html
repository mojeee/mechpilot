ISO 7200 title block: the data fields of a drawing

The data fields of a title block or document header: what identifies a drawing, what describes it, and who is responsible for it.

Total width: 180 mm. ISO 7200:2004, clause 6: 'The total width is 180 mm to fit an A4 sheet, with the left margin being 20 mm and the right margin 10 mm. The same title block is used for all paper sizes.' Position on the sheet: ISO 5457 (library/sheets/iso-5457.json).

ISO 7200:2004, 5.1 Table 1 (identifying), 5.2 Table 2 (descriptive), 5.3 Table 3 (administrative); M = mandatory, O = optional. maxChars = the standard's recommended number of characters (null = 'unspecified'). nameIt is MechPilot's own translation: the Italian text of UNI EN ISO 7200 was not available.

ISO 7200:2004 gives no lettering heights for the fields. MechPilot's choice (library/lettering/iso-3098.json, `default`): labels 2.5 mm, values 3.5 mm, identification number 5 mm, all ISO 3098 type B vertical.

Notes from the data file

  • Scale, projection symbol, general tolerances and surface texture are not title-block fields in ISO 7200:2004: they are 'handled dynamically and presented outside the title block only when used' (clause 4). ISO 5455:1979, 4.1 asks for the main scale in the title block; MechPilot shows it in an extra row above the block (its own choice).
  • Figure 2 of the standard shows an alternative arrangement with the person-name fields on an additional line.
  • Data fields such as creator and approval person may be shown in a separate document part, e.g. a revision description (5.3.1).
