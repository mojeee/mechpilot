ISO 261:1998, Table 2, column 'coarse'; same values in ISO 2306:1972, Table 1. ISO 2306:1972, Table 1, column 'Drill diameter'.

drill diameter ≈ nominal diameter − pitch — ISO 2306:1972, clause 1: the sizes of drills for parallel screw threads of normal length of engagement, the drill diameter being approximately equal to the nominal diameter of the thread minus the pitch

Note del file di dati

  • ISO 2306:1972, clause 0: the hole a drill makes depends on the drill point, the material, the lubricant and the machining conditions; in soft materials the tapped minor diameter can end up smaller than the drill. The table is a guide for conventional (cutting) tapping; it does not apply to thread forming.
  • ISO 2306:1972, clause 1: the drill diameters, except four sizes the standard marks with an asterisk, are selected from the ISO/R 235 twist drill sizes; stocked drill diameters should be used whenever possible (clause 0).

Fonte e verifica

Le citazioni dal file di dati sono in inglese, come sono scritte lì.

primary (è stato visto il testo stesso della norma)
Verificato su
  • https://law.resource.org/pub/in/bis/S01/is.10952.1984.pdf (IS 10952:1984, identical with ISO 2306:1972: clauses 0, 1 and 3.1, Table 1; read from the rendered page on 2026-10-22)
  • https://law.resource.org/pub/in/bis/S01/is.4218.2.2001.pdf (IS 4218 (Part 2):2001, identical with ISO 261:1998: clause 5, Table 2; read from the rendered pages on 2026-10-22)
Note sulla verifica
  • pitch and drill were read from ISO 2306:1972 Table 1 (nominal diameter, pitch, minor diameter limits for 5H/6H/7H, drill diameter). Every pitch agrees with the coarse column of ISO 261:1998 Table 2.
  • ISO 2306:1972 Table 1 ends at M56. M60 (pitch 5.5) and M64 (pitch 6) have coarse pitches in ISO 261:1998 Table 2 but no drill in ISO 2306; they are left out (see docs/to-verify.md). Use `rule` for them only with the user's confirmation.
  • ISO 262 (selected sizes for bolts, screws and nuts) was not read; the sizes here are the ones ISO 2306 lists, which include second- and third-choice diameters (M1.8, M2.2, M3.5, M4.5, M7, M9, M11, ...) of ISO 261.
