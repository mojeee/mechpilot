ISO 273:1979, clause 2, table: thread diameter d and clearance hole d_h, series fine / medium / coarse

Classi di tolleranza: ISO 273:1979, clause 2, note below the table: tolerance fields given for information only, for use where it is desirable to specify tolerances

Note del file di dati

  • Default series: medium. ISO 273:1979 does not name a default series; medium is the usual choice for general-purpose bolted joints and is MechPilot's own choice. The user can switch to fine or coarse per hole.
  • ISO 273:1979, clause 1: the values are for general-purpose applications and come from bearing-area calculations with the ISO bolt and nut product standards; clearance holes for special applications are chosen from the design requirements.
  • ISO 273:1979, clause 2, last note: where the edge of the hole would interfere with the underhead fillet of the bolt, a chamfer is recommended.

Note sulla verifica
  • Every diameter below was read from the table in ISO 273:1979 clause 2 (IS 1821:1987, an identical adoption). The national foreword uses the decimal point; the table itself uses the decimal comma.
  • ISO 273:1979 lists thread diameters from 1 mm to 150 mm. MechPilot stores M1.6 to M64; M1, M1.2, M1.4 and M68 to M150 are in the standard but not stored here (not needed by the kernel yet).
